# 云杉计划：完全虚构示例

这是一个**完全虚构**的示例项目，用于展示 PowerPresent 的版式、组件、配色和底图。

- 项目名、场景、数字、站点、路线和结论全部为虚构。
- 不对应任何真实项目，也不包含任何原始汇报稿的内容。
- 示例数据只用于展示图表和版式，不代表任何真实结果。

## 页面

11 页，3 章：问题、方案、验证。

1. 封面
2. 章节：问题
3. 问题：设备越多，异常越难在第一时间被发现
4. 原则：把判断放到边缘，只上报结论
5. 架构：感知、边缘、平台三层
6. 运行链路：采集 → 聚合 → 判断 → 上报
7. 集中式与边缘式：同样的覆盖，不同的上报量
8. 示例数据：上报量降了一个数量级
9. 路线：先试点，再扩展，最后平台化
10. 风险与应对：先把最坏情况写出来
11. 结尾

## 构建

```bash
python examples/demo/build.py
```

输出四份 PPTX（`journal` / `ink` × 浅色 / 深色）和 `out/preview/` 下的逐页预览。
